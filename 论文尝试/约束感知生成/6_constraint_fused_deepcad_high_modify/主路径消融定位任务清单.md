## 0. 使用规则

1. 本清单按 Phase 0 到 Phase 5 顺序推进，Gate 未通过前不建议进入下一阶段。
2. 所有实验默认保持 CAD-only：`alpha=0`、`beta=0`、`gamma=0`、`--disable_soft_geometry`。**例外 1：阶段 2c A2c** 为 A2b 续训 + 温和辅助（`enable_soft_geometry`，`aux_schedule warmup`），不得传 `--disable_soft_geometry`。**例外 2：阶段 2d A2d** 为**从头训练 300 epoch**，开启 hard BCE（`--use_hard_geom_bce`）与 interpreter 起点修复（`--use_corrected_line_start`），`gamma` 四路拆分（`--gamma_horizontal/--gamma_vertical/--gamma_parallel/--gamma_perpendicular`，**不传单值** `--gamma`），不得传 `--disable_soft_geometry` / `--init_weights_from`。
3. 每个实验必须使用独立 `exp_name`，禁止覆盖 `cf_high_modify_cad_only_100`。
4. 所有实验主 decoder 必须保持 latent-only，即主生成路径仍为 `P(S | z)`。
5. 优先用 `ckpt_epoch20` 做早期筛选；若指标接近或优于 H1，再继续看 `ckpt_epoch50/100`。
6. `ACC_param` 的判定必须结合参数分项，尤其是 Line、Arc 和 Ext 中部参数。
7. 若从 checkpoint 恢复训练导致 `train_metrics.csv` 出现重复 step，统计时必须保留同一 step 的最后一次写入或单独标注恢复段。
8. **A2 不替代 A3/A4**：合并实验（A2）用于快速筛选；单因素 A3、A4 用于归因，均为必做项。
9. **A2b 不替代 A2**：A2 反映 high_modify 默认 `masked_mean`（Projected + Bottleneck512）；A2b 与 `cf_simplify_modify2`（S2）对齐，用于公平对比 `loss_args` 并隔离实现栈影响。
10. **训练 loss 对比口径**：与 S2 比 `loss_args` 用 **A2b**；与 H1 / 原始 DeepCAD 比 **ACC** 用 H1 与各消融 checkpoint。
11. **A2c 不替代 A2b CAD-only 结论**：A2c 验证「主路径闭合后开启辅助」；预训练权重仅来自 A2b `ckpt_epoch20.pth`（`--init_weights_from`，勿 `--continue` 覆盖 A2b 目录）。
12. **A2d 不替代 A2c**：A2d 旨在突破 A2c 的 `parallel=0.84` 平台，**与 A2c 权重不共享**（从头训练 300 epoch）；`use_corrected_line_start` 修复后 `unit` 语义改变，A2d 与 H1/A2/A2b/A2c 不可直接比训练 loss 中的 `geom_*` 绝对数值，但 `loss_args` / `ACC_param` / `parallel` / `perpendicular` 等指标仍可比。
13. **A2d 早停**：warmup 中点 `ckpt_epoch70` **必须**与 ep50 比 `loss_args` epoch 内均值；若 ep70 突增 **>1.5×** ep50，立即停训，降 `--hard_geom_bce_scale 4.0` 或 `--gamma_parallel 2.0` 重启。

## 7. 当前首轮推荐

首轮建议顺序：

```text
A1 → A2 → A2b → A2c（mild 辅助）→ A2d（hard BCE 300 epoch）→ A3 + A4（单因素）
```

- **A1**：最小单因素，只验证 `constraint_tags` 加性偏置。
- **A2**：`dim_z=256` + joint masked mean（**当前代码实现**）；ACC@18 已优于 H1@20，待写 P3-03 结论。
- **A2b**：与 S2 同 pooling/bottleneck；**已闭合**（@20 `ACC_param=0.9380`）；默认栈 **plain mean + DeepCAD bottleneck**。
- **A2c**：从 A2b `ckpt_epoch20` 续训；首跑 **1.0/0.5/1.0**，warmup **21–31**；对照 A2b@20 与 H2 历史记录；**已停于 latest@114**（`parallel`=0.8428@100，仍 < DeepCADOrigin@1000=0.8617）。
- **A2d**：A2c 闭合后做；**A2b 栈从头训练 300 epoch**；interpreter 起点修复 + `geom_loss` hard BCE 双向 + `γ` 四路拆分（`γ_para=3`）+ 三段调度（1–50 CAD-only / 51–90 warmup / 91–300 full）；**目标突破 `parallel=0.8617`**，越过 DeepCADOrigin@1000 的上限；以 A2c@100 为对照基线；warmup 中点 ep70 必须监控 `loss_args` 冲击。
- **A3/A4**：分解维度与 pooling，不可被 A2/A2b 替代；可与 A2c / A2d 并行。

若 **G2c 通过**，论文「主路径 + 约束」以 A2c-mild 为准；**若 G2d 通过**（A2d@200 `parallel ≥ 0.86` 且 `ACC_param` 不显著退化），则 A2d 替代 A2c 成为论文主推；若 A2d 未越过 0.8617 且 A2c `ACC_param` 降 >2%，保持 A2b CAD-only。A7 采用 **A2b 栈**（非 G2 旧表述的仅 cad_only）。
