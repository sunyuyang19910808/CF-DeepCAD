## 6. 统一训练 loss（每 5 epoch，epoch 内均值）（基于训练集）

统计口径：`train_metrics.csv` 按 `step` 去重（保留最后一条）后按 epoch 求均值（`artifacts/train_metrics_per_epoch.csv`）。`loss_args` 已含 `loss_args_weight=2.0`。

读表说明：

- **D0**：原始 DeepCAD `train.py` 路径；**`loss` ≈ `loss_cmd` + `loss_args`**（分项日志，**非** CF 的 `loss_args_weight=2.0` 口径）；辅助列占位 **0**。
- **H1**：`α=β=γ=0` 且 `enable_soft_geometry=false`；**进反传总 `loss` = `loss_cmd`**；`geom_loss=0`，`pred_loss`/`recon_loss`/`geom_*` 仅日志。
- **A2**：与 H1 相同 CAD-only；改动：`dim_z=256`、`pooled_dim=256`、`masked_mean`（**ProjectedMaskedMeanPooling + Bottleneck512**）。

### 6.6 A2d 性能优化记录（P2d-02b + dataset cache，2026-05-24）

**背景**：初版 A2d 实现中 `use_corrected_line_start` 走 Python 三层循环（batch × line × scan），每步含 `.item()`/`.tolist()` GPU 同步，导致单 epoch 训练时间远超 A2c；另：`__getitem__` 每 epoch 重复 CPU 约束提取（161k 样本 × 300 epoch 纯浪费）。

**改造项**（已合入 `constraint_fused_deepcad_simplify_modify2_low_riskbased_high_modify`）：

| 项 | 文件 | 改动摘要 |
| --- | --- | --- |
| A | `application/differentiable_sketch_interpreter.py` | corrected / legacy 全向量化；segment-aware `cummax` 求 prev curve；fancy index scatter |
| B | `application/geometry_constraint.py` | `pos_weight` 懒缓存；unary/pair 各 stack 后 1 次 BCE（4→2 次） |
| C | `application/train_use_case.py` + `train.py` | `compute_metrics` 开关；`geom_*` 与 `.item()` 仅在 `log_frequency` 步执行 |
| D | `config/config_constraint_fused_high_modify.py` | `--save_frequency` 默认 **5→10** |
| E | `infrastructure/dataset_high_modify.py` + `dataset_cache_high_modify.py` | **`--dataset_cache disk`**：约束 GT 落盘；key 由 extractor 参数哈希；epoch 2+ 跳过重复 CPU 预处理 |

**验证**：

| 检查 | 命令 / 证据 | 结果 |
| --- | --- | --- |
| 功能 smoke | `python -m ...verify_p2d` | `checks_passed=true`；`corrected_unit_smoke.unit_err=0`；legacy `sum_matches_geom_loss=true` |
| GPU 微基准 | `python -m ..._bench_a2d --batch_size 64 --seq_len 60` | 旧 **3313 ms/iter** → 新 **8.5 ms/iter**（**~388×**）；关 metric **6.8 ms/iter** |
| disk cache smoke | `--dataset_cache disk` 同样本二次加载 | 首次 ~8 ms → 命中 ~2 ms；落盘 `data/.cache/high_modify/{key}/train/*.pt` |
| 兼容性 | A2c `state_dict` 无新增 buffer | 旧 checkpoint 可 `strict=True` 加载 |

**对 A2d 长训的影响**：GPU 步与 A2c 同量级；**须 `--dataset_cache disk`** + **`batch_size=256`**；ep1 后推荐 **`--num_workers 4`**（~1.33 s/it）；epoch 1 建 cache，epoch 2 起单 epoch wall-time 显著下降；300 epoch 默认 periodic ckpt **30 个 + latest**（约 **6 GB** ckpt + 数 GB cache）。**P2d-03 实测**（2026-05-25）：初训 `num_workers=0` ~2.46 s/it → 重启后 ~1.33 s/it。
