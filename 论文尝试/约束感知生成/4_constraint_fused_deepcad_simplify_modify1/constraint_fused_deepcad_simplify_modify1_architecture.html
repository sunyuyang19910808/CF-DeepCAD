Modify1 关键设计点

编码侧保留 AxisTagEmbedding、EncoderSimplify、Bottleneck，不恢复 ConstraintTokenEncoder 或 E_joint。
解码侧新增增加 ConstraintPredHead，只预测 Horizontal / Vertical 两类标签，不引入 decoder Cross-Attn(C)。
几何侧新增增加 DifferentiableSketchInterpreter 与 ConstraintEvaluator，对输出参数做 soft 几何解释并计算 H/V 残差。
重建侧保留AxisReconHead 继续保留，承担 latent z 的 H/V 语义重建监督。
总损失L_total = L_cmd + α·L_constraint_pred + β·L_axis_recon + γ·L_geom_constraint。
冻结范围只考虑 Horizontal、Vertical；不引入 Parallel、Perpendicular、Collinear。
明确删除项无 pair_gt / pair_pred / pair residual；无 token 双流；无 external constraint memory。
验证目标回答“监督更深但结构仍轻量”时，H/V 指标是否比原 simplify 更有效提升。
